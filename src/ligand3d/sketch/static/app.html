Wedges and dashes: pick the wedge-bond tool, then click a bond for a solid wedge and click the same bond again for a dashed (hashed) bond — the tool cycles wedge → dash → plain. A wedge and a dash give opposite R/S. Double-bond geometry is read as E/Z automatically.

Writes <name>.annotated.cif: the ligand as context for RFdiffusion4-Proteina, plus a collapsed segment for the protein to build around it. mask = conditioned — the columns say what to hold fixed, and diffusion is the absence of conditioning. Leave the length empty to condition on the ligand alone and supply the contig yourself.
Runs left to right. The first method searches the conformers; the rest refine only the survivors, so put the cheap one first.
Tracing draws the curve below and reports the change per step. The trajectory is written as <name>_traj.pdb, one MODEL per step.
Only the neural potentials are slow enough on CPU to be worth queueing. The job runs in an Apptainer image that has a CUDA build of torch, which this environment does not; a copy of the source goes with it, so editing the repo cannot change a job already in the queue. The page waits for the result.
Runs Rosetta's molfile_to_params.py. Extra conformers become the rotamer library, and the code is checked against Rosetta's residue_types.txt first. No PDB is needed — the SDF is fed straight in.
